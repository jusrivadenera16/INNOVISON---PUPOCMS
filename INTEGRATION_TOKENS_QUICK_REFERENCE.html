📡 API Usage for External Systems

Required Headers

Every API request must include these two headers:

REQUIRED HEADERS X-External-Api-Key: YOUR_TOKEN_HERE X-External-System: SYSTEM_KEY Content-Type: application/json

Example Request

CURL curl -X GET "https://clinic.domain.com/api/external/admin/profile" \ -H "X-External-Api-Key: YOUR_TOKEN_HERE" \ -H "X-External-System: ris" \ -H "Content-Type: application/json"
JAVASCRIPT const response = await fetch('https://clinic.domain.com/api/external/admin/profile', { method: 'GET', headers: { 'X-External-Api-Key': 'YOUR_TOKEN_HERE', 'X-External-System': 'ris', 'Content-Type': 'application/json' } }); const data = await response.json();
PYTHON import requests headers = { 'X-External-Api-Key': 'YOUR_TOKEN_HERE', 'X-External-System': 'ris', 'Content-Type': 'application/json' } response = requests.get( 'https://clinic.domain.com/api/external/admin/profile', headers=headers ) data = response.json()

🛡️ Security Best Practices

🚨 Critical: Never commit tokens to version control or share via email.

✅ DO

  • Use HTTPS only (never HTTP)
  • Store tokens in environment variables
  • Use secure password managers
  • Rotate tokens every 6-12 months
  • Revoke immediately if exposed
  • Use separate tokens per system

❌ DON'T

  • Commit tokens to Git/GitHub
  • Share via email or chat
  • Hardcode in source code
  • Log or expose in error messages
  • Use same token for multiple systems
  • Forget to revoke old tokens

Example: Secure Storage (.env)

.env FILE RIS_API_TOKEN=abc123xyz789def456uvw... RIS_API_URL=https://clinic.domain.com/api/external RIS_SYSTEM_KEY=ris IMS_API_TOKEN=ghi789rst345jkl012mno... IMS_API_URL=https://clinic.domain.com/api/external IMS_SYSTEM_KEY=ims

🔧 Error Handling & Troubleshooting

Error Status Code Cause Solution
Unauthorized 401 Invalid or revoked token Request new token from admin
Forbidden 403 Wrong system key Verify X-External-System header
Bad Request 400 Missing or malformed headers Check both required headers are present
Not Found 404 Endpoint doesn't exist Verify API endpoint URL
Server Error 500 Server-side issue Contact admin support

🧪 Testing Your Integration

Quick Test

Run this command to verify your setup (replace placeholders):

TEST COMMAND curl -i -X GET "https://your-clinic-domain.com/api/external/admin/profile" \ -H "X-External-Api-Key: YOUR_ACTUAL_TOKEN" \ -H "X-External-System: ris" \ -H "Content-Type: application/json"

Expected Response

✓ Success: HTTP 200 OK with JSON response containing admin data

Common Issues

  • 401 Unauthorized: Token is invalid or revoked → Request new token
  • 403 Forbidden: Wrong system key → Check exact spelling
  • 400 Bad Request: Missing headers → Include both required headers
  • Connection refused: Wrong URL → Verify domain and protocol (HTTPS)
